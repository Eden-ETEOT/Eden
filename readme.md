# Eden Systems

Sistema de gestão condominial — controle de ocorrências, comunicação e administração de condomínios.

**TCC do curso de Informática** — desenvolvimento de um SaaS web para síndicos e moradores.

## Tecnologias

- PHP 8 com PDO e MariaDB
- HTML5, CSS3 (design system próprio) e JavaScript
- PHPMailer para envio de e-mails

## Funcionalidades

- Landing page institucional
- Cadastro e autenticação de usuários
- Recuperação de senha por e-mail
- Dashboard do síndico com estatísticas e ocorrências
- Gerenciamento de chamados, moradores, unidades e condomínios
- Design system próprio com botões, cores e tipografia

## Equipe

Projeto desenvolvido por alunos do curso de Informática.
