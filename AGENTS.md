# Instruções para agentes

## Git / Branches

- A branch base é sempre a `beta`.
- Para qualquer alteração no repositório, crie uma branch nova a partir da `beta`. Nunca altere/commite direto na `beta` ou em outra branch existente.
- Nome da branch nova: `beta-<o-que-esta-sendo-adicionado>`, em minúsculas, com hífens. Exemplo: `beta-login`.
